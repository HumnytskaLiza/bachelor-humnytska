Employee Onboarding Platform - це прототип веб-системи для проведення онбордингу нових працівників у малих компаніях. Система підтримує створення персоналізованих шляхів онбордингу із завданнями, відстежує інформацію про нових співробітників та містить базу корпоративних докуміентів і тренінгових матеріалів. Однією з її особливостей є присутність інтелектуального помічника на базі штучного інтелекту, який надає контекстну підтримку та відповідає на запитання, пов’язані з компанією та внутрішніми процесами. Система побудована за допомогою Next.js, Tailwind CSS, Supabase та OpenAI (Vercel AI SDK) і розгорнута на Vercel.


## Запуск Системи

### Локально

```bash
pnpm install
pnpm dev
```

Після цього запустіть наступне посилання у браузері: [http://localhost:3000](http://localhost:3000).
